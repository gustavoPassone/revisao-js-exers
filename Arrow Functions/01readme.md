1. Dobro: Converta function dobro(n) { return n * 2 } para arrow function.

2. Saudação fixa: Crie uma arrow function que retorne a string "Olá, Mundo!" sem receber parâmetros.

3. Soma simples: Crie uma arrow function que receba a e b e retorne a soma.

4. Verificar Par: Crie uma função que receba um número e retorne true se for par e false se for ímpar.

5. Quadrado: Crie uma arrow function que retorne o quadrado de um número usando a sintaxe de retorno implícito (sem as chaves {}).

6. Maioridade: Receba uma idade e retorne "Maior de idade" ou "Menor de idade" usando um operador ternário dentro da arrow function.

7. Conversão de Moeda: Crie uma função que receba um valor em Dólar e retorne o valor em Real (considere a taxa de 5.0).

8. Template String: Crie uma arrow function que receba nome e idade e retorne: "Olá, meu nome é [nome] e tenho [idade] anos".

9. Multiplicação por 10: Crie uma função de uma única linha que multiplique um valor por 10.

10. Comprimento de String: Receba uma string e retorne a quantidade de caracteres dela.
